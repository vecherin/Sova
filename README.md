# Сова

Планировщик с совой-питомцем. Работает в браузере и ставится на экран «Домой» на iPhone: Safari → «Поделиться» → «На экран „Домой“».

Все дела хранятся только в телефоне, на сервер ничего не уходит.

Сайт собран из исходников проекта командой `python3 build.py sofia`; эта папка — готовая сборка.
